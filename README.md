# EUM Mid Term Examination — info-beamer v2.2

Date-wise Fall 2026 examination display for Emerson University Multan, Faculty of Computing & Emerging Technologies.

## Included
- Official `exam.json` data (412 entries / 69 sections as supplied)
- Date tabs, date-wise exam table, and automatic pagination
- Live Pakistan Standard Time (UTC+5)
- NOW current-exam panel and NEXT chronological exam-slot panel
- Full exam details: course code/title, date, time, room, invigilator, students
- Rotating upcoming section labels in the footer

## Package contents
`package.json`, `node.json`, `node.lua`, `exam.json`, `logo.png`, `font.ttf`, `font-bold.ttf`, `package.png`.

## Install
Upload this ZIP through info-beamer Packages > Add package, create a setup, and assign it to the Raspberry Pi. The rendering should be checked on the actual Pi because the final layout depends on the device's info-beamer runtime.

## Data note
The bundled exam data is copied from the provided CSET Mid Term Examination Fall 2026 JSON. Please verify official room/invigilator assignments before operational use.
